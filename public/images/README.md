# Static Assets Directory

Place your static images in the appropriate subdirectories:

- `public/images/brand/` -> Logos, emblems, favicons, badges
- `public/images/hero/` -> Hero banners, desktop/mobile slider visuals, background videos
- `public/images/products/` -> Flower jars, pre-rolls, seeds, apparel
- `public/images/strains/` -> Bud macro shots, terpene graphics
- `public/images/gallery/` -> Cultivation facility, lifestyle, lookbook photos
